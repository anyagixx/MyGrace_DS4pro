# Migrating to MyGRACE v2.0 (surface consolidation)

v2.0 removes redundant commands, MCP tools and skills. There are **no
deprecated aliases**: old spellings are gone on purpose, so agents must use the
smaller surface. This is a breaking change; v1.x callers should update here.

## CLI: 23 → 18 top-level commands

| v1.x | v2.0 |
|---|---|
| `mygrace verify [--module M-X] [--compact]` | `mygrace verify [--module M-X]` (always compact; the full run is the default) |
| `mygrace context packet M-X` | `mygrace context packet M-X` |
| `mygrace context focus M-X` | `mygrace context focus M-X` |
| `mygrace context cost` | `mygrace context cost --path .` |
| `mygrace setup init` | `mygrace setup init` |
| `mygrace setup install` | `mygrace setup install` |
| `mygrace setup doctor` | `mygrace setup doctor` |

Everything else is unchanged: `ci`, `lint`, `status`, `trust`, `verify`, `module`,
`phase`, `verification`, `file`, `context`, `setup`, `trace`, `impact`, `next`,
`projects`, `integrations`, `diagram`, `capsule`.

`mygrace verify` keeps the trust/deny-list/audit behavior of the old `test`
command; `verify` is the single way to execute project-declared checks.

## MCP: 25 → 21 tools

| v1.x tool | v2.0 |
|---|---|
| `mygrace_verify` | `mygrace_verify` |
| `mygrace_context` | `mygrace_context { mode: "packet" }` |
| `mygrace_context` | `mygrace_context { mode: "focus" }` |
| `mygrace_context` | `mygrace_context { mode: "cost" }` |
| `mygrace_find_modules` | `mygrace_find_modules` (no query lists everything) |

All other tools are unchanged. `mygrace_trust` additionally accepts
`check`/`revoke`; `mygrace_verify`'s unsafe-command opt-in moved to
`mygrace_verify` (`allowUnsafeCommands`).

## Skills: 15 → 12

| Removed skill | Now part of |
|---|---|
| `mygrace-token-budget` | `mygrace-cli` (output-budget section) |
| `mygrace-setup-subagents` | `mygrace-multiagent-execute` (role prompts) |
| `mygrace-refresh` | `mygrace-reviewer` (recovery/index-refresh section) |

Install the new skill set with `mygrace setup install` (or rerun it after
upgrading); the DSH skills directory is updated in place.

## Why

The review found the public surface too large for the core value ("map +
verification"). v2.0 keeps the same capabilities with fewer entry points; the
quickstart (`docs/quickstart.md`) recommends only `mygrace next` and
`mygrace ci` for daily work. Command/tool/skill counts are enforced by the
docs/marketplace validators.
